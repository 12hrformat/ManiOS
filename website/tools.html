Toolset

Curated, not comprehensive. Tools are chosen deliberately and tiered by implementation difficulty.

Easy

Tools that should generally work immediately after installation.

Nmap Netcat Tcpdump Dig / DNS Curl Wget FFUF SQLmap Nikto Nuclei WhatWeb Hydra John the Ripper Hashcat YARA Python DragonRepo

Moderate

Straightforward to install but may need additional dependencies or configuration.

Masscan Amass Subfinder HTTPX Naabu Gobuster Feroxbuster Impacket NetExec SearchSploit Metasploit Radare2 Rizin Binwalk Volatility

Hardware / Environment

Require specific hardware, drivers, interfaces, permissions, or external environments.

Aircrack-ng Kismet Wifite Bettercap Mitmproxy Evil-WinRM Kerbrute BloodHound

GUI / Later

Integrate after the Mani GUI environment is available.

Ghidra Burp Suite Wireshark Cutter BloodHound GUI Autopsy Tshark (CLI alt) Rizin (CLI alt)

Testing Standard

Every preinstalled tool must pass three stages:

1. INSTALLED 2. LAUNCHES 3. FUNCTIONALLY TESTED

A tool should not be considered fully supported by Mani merely because its package installs successfully.
