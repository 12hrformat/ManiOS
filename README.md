## About

Mani OS is a Linux distribution built around cybersecurity, security research, CTFs, and everyday computing.

The project started with a simple idea: build a security-focused operating system that doesn't feel like a pile of tools thrown onto a desktop.

Mani OS aims to provide a clean base system, a carefully selected set of security tools, sensible defaults, and an environment that still works well as a normal desktop OS.

This is an independent project — the base distribution, package management system, and other core components are still being decided.

---

## What We're Building

### 🔐 Security

A focused toolset covering:

- Network security
- Web security
- Digital forensics
- Reverse engineering
- Malware analysis
- OSINT
- Defensive security
- General security research

Tools are chosen individually rather than dumping every available security package into the default install.

### 🏴 CTFs

Mani OS is meant to work well out of the box for CTF environments, with commonly used tooling available without a lot of manual setup.

### 🖥️ Daily Use

Security tooling shouldn't make the rest of the OS unpleasant to use. Mani OS also focuses on:

- A usable desktop environment
- Reasonable resource usage
- Reliable updates
- Clear documentation
- Normal desktop applications
- Being usable outside of security work

---

## Design Principles

| Principle | What it means |
|---|---|
| **Curated, not bloated** | A smaller set of useful tools maintained properly beats hundreds of packages nobody touches. |
| **Practical** | The OS should solve problems, not create new ones. |
| **Independent** | Built as its own project, not a rebrand of another security distro. |
| **Maintainable** | Nothing gets added unless it can realistically be maintained. |
